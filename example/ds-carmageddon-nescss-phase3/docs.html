hud styled

A panel that sits flush in the HUD grid.

Class
cm-panel
Diverges
NES.css centres a container's title over its border, which is right for a dialogue and wrong inside a grid — the overhang breaks alignment with the panel beside it. This override lays the panel out as a flex column with the system's own spacing and drops the overhang. Everything else, including the pixel border, stays the library's.
