A second product on the same foundation, reaching different conclusions. Dark by default with no light counterpart, neon cyan and magenta as the two brand roles, and a vocabulary of four button patterns — one of which the Hot Tone example forbids.

Phase 2 means each allowed pattern has been promoted to a semantic class in patterns.scss. There is no component framework here, so phase 2 is the end of the line rather than a step toward a wrapper — a complete stopping point.

Two products, one foundation, opposite conclusions

The ghost pattern is allowed here and forbidden in Hot Tone. The trade-off is identical — a borderless control can read as text — and the products resolve it differently, because this one's surfaces are dark panels with visible chrome so the affordance survives.

That disagreement is the argument for keeping the vocabulary in the product rather than in the tool. A foundation that shipped an opinion here would be wrong for one of these two, and the tool cannot know which.
