recipe raw

The horizontal recipe row. The only card shape this product has.

Class
card card-side
Diverges
daisyUI lets a side card's image size itself from its content, which gives a ragged left edge down a list. This product's list is scanned vertically, so the images are pinned to a fixed column and cropped to fill. Geometry only — the card's colour, radius, border and padding all still come from the theme.

menu raw

The primary sidebar. How the product moves between sections.

Class
menu
Diverges
daisyUI paints the active item with `neutral` — the library treating navigation as chrome. This product's navigation carries its only brand colour, so the active item takes `action` instead. Not a colour correction: the theme was right and the ROLE assignment was the library's, which is a decision only the product can make.

chip

A selectable filter token. daisyUI has a button and it has a badge; it has no control that is clickable, carries a selected state and reads as a label.

chip styled

One filter value. Pressed state carried by `aria-pressed`, so the accessible name and the visual state cannot drift apart.

Class
mc-chip
Note
Built from tokens rather than from `.btn`. Inheriting a button's height and padding is what makes a filter row look like a toolbar, which is the opposite of what a filter row should look like.
