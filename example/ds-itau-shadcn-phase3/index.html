Dúvidas frequentes

Como emito a 2ª via de um boleto?
No app, entre em Pagamentos › Boletos e escolha o boleto desejado. A 2ª via é gerada com a data de vencimento atualizada.
Onde encontro o código do operador?
É o número de três dígitos definido na abertura da conta. Se não lembrar, use o acesso por CPF.
Posso alterar o limite do Pix pelo site?
O valor sim; a janela de horário só pelo app, por exigência de segurança.
