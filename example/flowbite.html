Flowbite adapter

A library whose theming surface is Tailwind's @theme, written as semantic names — --color-brand, --color-body, --color-neutral-primary. The mapping to layer 2 is close to one-to-one.

Buttons

Note text-on-brand rather than Flowbite's own text-white. Flowbite has no "text on brand" token, which puts the foreground half of the pair in the markup where no adapter can reach it — so this adapter publishes the missing companions.

Surfaces

Flowbite names surfaces by prominence — primary, secondary, tertiary — where layer 2 names them by role: page, surface, raised, sunken. They run parallel in a light theme, which is why the mapping stays clean.

What this page is testing:
  • A library with no vocabulary to translate. No component classes, no --fb-* namespace. Flowbite is a semantic token layer that happens to ship markup — which makes it the closest thing here to a peer rather than a target.
  • Prominence versus role. Flowbite says primary / secondary / tertiary; layer 2 says page / surface / raised / sunken. Both describe the same ramp, but role survives a theme inversion and prominence does not — "primary neutral" is white in one theme and near-black in the other.
  • The pair invariant has to be exported. Flowbite's own markup writes text-white on filled components, which is the pairing that fails WCAG on a mid-bright fill. The adapter publishes --color-on-brand and friends so the markup can name the paired foreground instead.
