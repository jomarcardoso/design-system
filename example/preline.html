Where the shapes disagree

Preline exposes a numbered primary ramp; layer 2 publishes chosen steps instead, because a ramp is a layer 1 concern and layer 1 is private. The numbered steps are compressed onto the decisions that exist, so components stay on-brand with a flatter ramp than Preline's own.

What this page is testing:
  • Independent confirmation of the layering. Preline splits decisions from bridge exactly as this project does, and uses @theme inline for the same reason — so the utility keeps the reference and follows a runtime theme swap. Nothing here needed translating because there was almost nothing to translate.
  • The pair invariant, arrived at twice. --primary-foreground, --destructive-foreground, --muted-foreground. Same rule, same reason: a fill without its text is a contrast bug waiting to happen.
  • Unprefixed names are a shared namespace. --primary, --border and --card are generic enough that a project may already own them — and daisyUI uses --border for a width where Preline uses it for a colour. One adapter per application.
