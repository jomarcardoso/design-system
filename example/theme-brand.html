What this page is testing:
  • A theme is data, not code. brand is one map of colour decisions in _themes.scss. The token count did not change — 110 names before and after — because a theme supplies values, never new names.
  • Action and selected finally diverge. In light both are indigo, and the README lists collapsing them as an open question. Here action is cocoa and selected is steel, and every library shows the split with no code change. That is what keeping them separate was for.
  • Status colours stay recognisable. A brand palette says what the product looks like; it does not get to say that danger is brown.
  • Two libraries cannot share a page. Bootstrap and daisyUI collide on 158 class names. The design system makes them agree on colour; it cannot make them agree on who owns .btn. Choose one per application — which is what $adapters is for.
